# 案件001 precheck（C# 版）：大腸カメラ予約で「事前診察」が無い患者を知らせる

Wakumy の予約一覧（**内視鏡タブ**）を今日から 45 日先まで見て、大腸の検査予約（例「胃＋大腸カメラ検査」）を集め、
外来診察タブの「大腸カメラ事前診察」と突き合わせます。事前診察が無い人を
**診察券番号（初診なら氏名＋生年月日）の一覧としてテキストファイルに書いてメモ帳で開き**、Windows の通知も出します。
一覧の下には、過去 30 日に外来受診が無い人と診察券番号が未登録の人を **※要チェック※** としてまとめます。

- **exe 1 個で動きます。** Python も .NET も入れる必要はありません。ブラウザは Windows 標準の Microsoft Edge を使います。
- 動かす場所：手持ちPC（インターネット側）。電カルネットワークには触れません。
- 実行時に **AI は使いません**。文字列の比較だけで判定します。
- メールやアカウントの設定は不要です。

## クリニックのPCでやること（5 分）

1. 渡された `precheck` フォルダを、消されない場所（例：`C:\precheck`）に置く。
2. `config.json` の `"id"` が、そのクリニックで使う Wakumy のログインIDか確認する。違えばメモ帳で書き換える。
3. **`setup.bat` をダブルクリック**。Wakumy のパスワードを聞かれるので入力して Enter（画面には表示されません）。
   `local\wakumy_password.txt` に保存されます。
4. **`動作確認.bat` → Enter**。ブラウザが開き、ログイン → 予約一覧 → 内視鏡タブ → 日付を 1 日ずつ進めて読む → 外来診察タブも同様 → 突合、と進みます。数分かかります。ファイルは作らず、何も記録しません。
5. **`手動実行.bat`** で本番を 1 回。該当者がいれば `結果\大腸カメラ事前診察なし_日付.txt` ができてメモ帳で開きます。
6. 自動で動かすなら、タスクスケジューラに `run.bat` を登録（下記）。黒い画面は Enter を 3 回押すと閉じます。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `precheck.exe` | 本体（.NET ランタイム同梱） |
| `.playwright\` | ブラウザ操作のドライバ。消さない |
| `config.json` | 設定。ID、判定ルール、見る日数、結果の置き場所 |
| `setup.bat` | パスワードを保存（初回だけ） |
| `動作確認.bat` | ブラウザを表示して本番と同じ流れを確認。記録は残さない |
| `手動実行.bat` | 本番を 1 回実行。画面に進み具合が出る |
| `run.bat` | タスクスケジューラ用。画面に出さず `state\run.log` に記録 |
| `local\` | パスワード。配布物に含めない |
| `state\` | 通知済みの記録、ログ、失敗時の画面 |
| `結果\` | 結果ファイル |

## 定期実行（タスクスケジューラ、4 日に 1 回）

1. タスクスケジューラ → 「基本タスクの作成」→ 名前「precheck 大腸カメラ事前診察チェック」。
2. トリガー「毎日」→ 開始日時を決めて、「間隔」を **4 日**にする。
3. 操作「プログラムの開始」→ プログラム: `run.bat` のフルパス。「開始（オプション）」: このフォルダのフルパス。
4. プロパティで「ユーザーがログオンしているかどうかにかかわらず実行する」にチェック。電源オプションの「スリープを解除してこのタスクを実行する」も有効に。
   ※ ログオフ中に動いた場合はメモ帳は開きません。`結果` フォルダのファイルと Windows 通知で確認してください。

毎回「今後 45 日分の検査予約」を全部見直すので、4 日に 1 回でも取りこぼしません。
知らせた「患者 × 検査日」は `state\processed.json` に記録され、同じ患者・同じ検査日には 1 回しか知らせません。

## 判定ルール（config.json の rules で変更可）

| 項目 | 既定値 | 意味 |
|---|---|---|
| exam_keywords | 大腸 | 予約メニューにこれを含めば「大腸の検査予約」 |
| exam_exclude_keywords | 連鎖用, 事前診察 | 枠確保用の連鎖予約と事前診察そのものは検査から除外 |
| pre_exam_keywords | 大腸カメラ事前診察 | 事前診察とみなすメニュー |
| window_days | 30 | 検査日の前 30 日以内に事前診察があれば OK |
| exam_active_statuses | 予約 | 検査予約として数えるステータス |
| pre_exam_ok_statuses | 予約, 来院 | 事前診察として数えるステータス（済んだ「来院」も含む） |
| recent_visit_days | 30 | ※要チェック※: この日数以内に外来受診が無い人を要チェックにする |

`schedule` の `days_ahead`（既定 45）で何日先の検査まで見るか、`days_back`（既定 30）で事前診察を何日前まで遡るかを変えられます。`days_back` は `window_days` 以上にしてください。

## 困ったとき

- 「ブラウザ「msedge」を起動できませんでした」→ Microsoft Edge が入っているか確認。Chrome を使うなら `config.json` の `"browser"` を `"chrome"` に。
- 日付移動や読み取りに失敗した → `state\debug_*.png` と `state\debug_day_*.txt` に画面が保存されます。患者情報が映るので、名前を隠して開発者に見せてください。
- パスワードを変えた → `setup.bat` をもう一度。

## 開発者向け：配布フォルダの作り方

配布フォルダ（`dist`）は 2 通りで作れます。

- **GitHub Actions**：`main` にこのフォルダの変更が入ると自動でビルドされます。GitHub の **Actions** タブ → `build-001-cs` → 最新の実行 → **Artifacts** の `precheck-001-windows` をダウンロードして展開すれば、そのまま渡せます。
- **手元のPC**：.NET SDK 8 を入れて `build.bat` をダブルクリック。`dist` フォルダができます。

テストは `dotnet test tests/Precheck.Tests/Precheck.Tests.csproj`。判定ロジック・画面文字の解釈・結果ファイルのテストで、Wakumy には接続しません。
