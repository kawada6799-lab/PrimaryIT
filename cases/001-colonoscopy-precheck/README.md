# 案件001 precheck：大腸カメラ予約で「事前診察」が無い患者を知らせる

Wakumy の予約一覧（**内視鏡タブ**）を今日から 45 日先まで見て、大腸の検査予約（例「胃＋大腸カメラ検査」）を集め、
外来診察タブの「大腸カメラ事前診察」と突き合わせます。事前診察が無い人を
**診察券番号（初診なら氏名＋生年月日）の一覧としてテキストファイルに書いてメモ帳で開き**、Windows の通知も出します。

- 初診で患者登録が無い人も、内視鏡タブには入るので漏れません。
- 動かす場所：**手持ちPC（インターネット側）**。電カルネットワークには触れません。
- 実行時に **AI は使いません**。文字列の比較だけで判定します。
- メールやアカウントの設定は不要です。
- 要件・判定ルール・画面の手順：`docs/cases/001-colonoscopy-precheck/`

## 使い方（Windows）

### 準備（初回だけ）

1. Python 3.12 以上を https://www.python.org/downloads/ からインストール（インストーラの最初の画面で「Add python.exe to PATH」に必ずチェック）。
   ※ Windows には「python」と打つと Microsoft Store を開くだけの偽の python が最初から入っています。setup.bat はそれを見分けて、本物が無ければ「Python が見つかりません」と表示します。
2. このリポジトリをPCに取得（GitHub の「Code → Download ZIP」で展開、または `git clone`）。
3. このフォルダ `cases\001-colonoscopy-precheck` の **`setup.bat` をダブルクリック**。
   - 必要なものを自動で入れたあと、Wakumy のパスワードを聞かれるので入力して Enter。
   - パスワードは `local\wakumy_password.txt` に保存されます。このフォルダは GitHub に上がりません。
   - ID は `config.toml` に書いてあります。変わったらそこを直します。

### 動作確認

4. **`動作確認.bat` をダブルクリック**。
   - 何も入力せず Enter すると、ブラウザが開いて ログイン → 予約一覧 → 内視鏡タブ → 日付を 1 日ずつ進めて予約を読む → 外来診察タブも同様 → 突合、と本番と同じ流れで動きます。数分かかります。
   - 患者名を「姓 名」で入力すると、旧方式（患者管理からその患者だけ確認）で動きます。
   - どちらもファイルは作らず、何も記録しません。黒い画面の「内視鏡 10/16: 予約 N 件」の数が画面と合っていれば OK です。
   - 黒い画面は Enter を 3 回押すと閉じます（結果を見る前に閉じてしまわないため）。
5. 途中で止まる場合は、画面の部品の探し方（`src\precheck\wakumy.py`）を実機に合わせて直します。
   ここだけは **Claude Code を先生のPCで動かして**、黒い画面のエラー文とブラウザの画面を見せながら直すのが早いです（開発時の AI 利用）。

### 本番

6. **`手動実行.bat`** で1回動かすと、予約通知一覧を読んで判定し、該当者がいれば `結果\大腸カメラ事前診察なし_日付.txt` を作ってメモ帳で開きます。
7. 自動で動かすには、タスクスケジューラに `run.bat` を登録します（下記）。

## 結果ファイルの中身

```
大腸カメラ事前診察の予約が無い患者  （2026/10/08 時点、2 名）

診察券番号  氏名             検査日時            予約メニュー
----------------------------------------------------------------------
12          テスト 花子      10/31(土) 13:30     大腸カメラ検査
535         テスト 太郎      11/02(月) 13:30     胃＋大腸カメラ検査

Wakumy の患者管理で診察券番号を検索し、事前診察の予約を取ってもらうよう連絡してください。
```

患者管理で名前が見つからなかった通知は、判定せずに **予約ID と氏名** を同じファイルの下に載せます。Wakumy で予約IDを検索して手で確認してください。

`config.toml` の `output_dir` を院内の共有フォルダにすれば、スタッフの誰でも同じファイルを見られます。

## Claude（AI）は実行時に不要

このプログラムは先生のPCに入れて、タスクスケジューラが勝手に動かします。Claude は動きません。
Claude Code を使うのは「初回の実機合わせ」と「Wakumy の画面が変わって動かなくなったとき」の2回だけです。

## 定期実行（タスクスケジューラ、4日に1回）

1. タスクスケジューラ → 「基本タスクの作成」→ 名前「precheck 大腸カメラ事前診察チェック」。
2. トリガー「毎日」→ 開始日時を決めて、「間隔」を **4 日**にする。
3. 操作「プログラムの開始」→ プログラム: `run.bat` のフルパス。「開始（オプション）」: このフォルダのフルパス。
4. 作成後にプロパティを開き、「ユーザーがログオンしているかどうかにかかわらず実行する」にチェック。
   電源オプションで「スリープを解除してこのタスクを実行する」も有効にする（PCが寝ていると動かない）。
   ※ ログオフ中に動いた場合はメモ帳は開きません。`結果` フォルダのファイルと Windows 通知で確認してください。

実行のたびに今後 45 日分の検査予約を全部見直すので、4 日に 1 回でも取りこぼしません。
知らせた「患者 × 検査日」は `state\processed.json` に記録され、同じ患者・同じ検査日には 1 回しか知らせません。
実行ログは `state\run.log` に追記されます。

## 判定ルール（config.toml の [rules] で変更可）

| 項目 | 既定値 | 意味 |
|---|---|---|
| exam_keywords | 大腸 | 予約メニューにこれを含めば「大腸の検査予約」 |
| exam_exclude_keywords | 連鎖用, 事前診察 | 枠確保用の連鎖予約と事前診察そのものは検査から除外 |
| pre_exam_keywords | 大腸カメラ事前診察 | 事前診察とみなすメニュー |
| window_days | 30 | 検査日の前 30 日以内に事前診察があれば OK |
| exam_active_statuses | 予約 | 検査予約として数えるステータス |
| pre_exam_ok_statuses | 予約, 来院 | 事前診察として数えるステータス（済んだ「来院」も含む） |
| notification_max_age_days | 5 | （旧方式のみ）これより古い通知は見ない |

`[schedule]` の `days_ahead`（既定 45）で何日先の検査まで見るか、`days_back`（既定 30）で事前診察を何日前まで遡るかを変えられます。
`days_back` は `window_days` 以上にしてください。

## メールでも知らせたい場合（任意）

`config.toml` の `[mail]` を `enabled = true` にして SMTP の設定を書き、環境変数 `SMTP_PASSWORD` を渡します。
Gmail の場合は 2 段階認証のうえ「アプリパスワード」が必要です。既定では使いません。

## 既知の制約

- 実機（先生のPC）での動作は未確認です。初回は `動作確認.bat` で画面を見ながら実行してください。
- 同姓同名の患者が複数いる場合は全員を確認し、該当があれば全員分を一覧に出します。
- 予約一覧の日付移動は「N 日後」の入力欄、だめなら左のカレンダーで行います。実機で違えば調整が必要です。
