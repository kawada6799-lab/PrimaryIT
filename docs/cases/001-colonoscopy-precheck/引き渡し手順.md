# 案件001 引き渡し手順（C# 版：exe 1 個をクリニックのPCに置く）

## 渡すもの

- GitHub の **Actions** タブ → `build-001-cs` → 最新の実行 → **Artifacts** の `precheck-001-windows` をダウンロードして展開したフォルダ。
  （手元で作るなら .NET SDK 8 を入れて `cases/001-colonoscopy-precheck-cs/build.bat`。`dist` フォルダができる）
- 中身：`precheck.exe`、`.playwright` フォルダ、`config.json`、`setup.bat`、`動作確認.bat`、`手動実行.bat`、`run.bat`、`README.md`。
- 開発で使ったフォルダの `local`（パスワード）、`state`、`結果`（患者情報）は**渡さない**。

## クリニックのPCでやること（5 分）

1. フォルダを消されない場所（例：`C:\precheck`）に置く。Python も .NET も入れなくてよい。Microsoft Edge が入っていればよい。
2. `config.json` の `"id"` が、そのクリニックで使う Wakumy のログインIDか確認する。違えばメモ帳で書き換える。
3. **`setup.bat`** をダブルクリック → Wakumy のパスワードを入力して Enter。
4. **`動作確認.bat`** → Enter で 1 回流し、結果の一覧が出ることを確認（数分）。
5. **`手動実行.bat`** で本番を 1 回。該当者がいれば `結果` フォルダにファイルができてメモ帳で開く。
6. タスクスケジューラに `run.bat` を登録する（`README.md` の「定期実行」参照）。4 日に 1 回の想定。
7. 看護師も結果を見るなら、`config.json` の `"output_dir"` を院内の共有フォルダに変える。

## 困ったとき

- 「Windows によって PC が保護されました」→「詳細情報」→「実行」。自作の exe なので署名が無い。
- 「ブラウザ「msedge」を起動できませんでした」→ Edge が入っているか確認。Chrome なら `config.json` の `"browser"` を `"chrome"` に。
- Wakumy の画面が変わって動かなくなった → `state\debug_*.png` と `state\debug_day_*.txt`（患者情報を含む）を名前を隠して開発者に見せる。実行時に AI は不要だが、直すときだけ Claude Code を使う。
- パスワードを変えた → `setup.bat` をもう一度。
