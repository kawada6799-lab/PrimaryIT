# 案件001 引き渡し手順（C# 版：フォルダ 1 つをクリニックのPCに置く）

## 渡すもの

- GitHub の **Actions** タブ → `build-001-cs` → 最新の実行 → **Artifacts** の `precheck-001-windows` をダウンロードして展開したフォルダ。
  （手元で作るなら .NET SDK 8 を入れて `cases/001-colonoscopy-precheck-cs/build.bat`。`dist` フォルダができる）
- 中身：`precheck.exe`（起動用）、`precheck.dll`（本体）と .NET の DLL 群、`.playwright` フォルダ、`config.json`、`setup.bat`、`動作確認.bat`、`手動実行.bat`、`run.bat`、`README.md`。DLL が多いが消さない。
- 開発で使ったフォルダの `local`（パスワード）、`state`、`結果`（患者情報）は**渡さない**。

## 初回だけ必要な 2 ステップ（署名の無い自作 exe のため。1 台につき 1 回）

1. **ブラウザのダウンロード保護**：ZIP をダウンロードすると「危険なダウンロードがブロックされました」と出ることがある。
   Chrome はダウンロード履歴の行の「＞」→「保持」（出なければ `chrome://downloads` で「危険なファイルを保存」）。Edge は「…」→「保存」→「このまま保存」。
2. **ウイルス対策の隔離**：展開後に `precheck.exe` が消えていたら、Norton なら「セキュリティ」→「履歴」→ 検疫の `precheck.exe` →「復元して除外する」。
   Windows セキュリティなら「保護の履歴」→「復元」または「デバイスで許可」。
   bat は `precheck.exe` が無いと英語でこの案内を出して止まる。

これを通せば以後は普通に動く。インストール不要の方針を優先し、コード署名証明書は案件が増えてから検討する。

## クリニックのPCでやること（5 分）

1. フォルダを消されない場所（例：`C:\precheck`）に置く。Python も .NET も入れなくてよい。Microsoft Edge が入っていればよい。
2. `config.json` の `"id"` が、そのクリニックで使う Wakumy のログインIDか確認する。違えばメモ帳で書き換える。
3. **`setup.bat`** をダブルクリック → Wakumy のパスワードを入力して Enter。
4. **`動作確認.bat`** → Enter で 1 回流し、結果の一覧が出ることを確認（数分）。
5. **`手動実行.bat`** で本番を 1 回。該当者がいれば `結果` フォルダにファイルができてメモ帳で開く。
6. タスクスケジューラに `run.bat` を登録する（`README.md` の「定期実行」参照）。4 日に 1 回の想定。
7. 看護師も結果を見るなら、`config.json` の `"output_dir"` を院内の共有フォルダに変える。

## 困ったとき

- ZIP は**先に右クリック →「すべて展開」**。ZIP の中で bat を開くと bat だけが一時フォルダに出て `precheck.exe not found` になる。
- 「'precheck.exe' は…認識されていません」/ `precheck.exe not found` → `precheck.exe` がフォルダに無い。ウイルス対策が隔離した可能性が高い（2026-10 に Norton が exe 1 個版を「Win64:Malware-gen」として検疫に移した実績あり。誤検出）。
  - Norton：通知の「検疫に移動しました」→ 復元。繰り返すなら設定 → ウイルス対策 → スキャンとリスク →「除外」にフォルダを追加。「誤検出を報告する」も押す。
  - Windows セキュリティ →「ウイルスと脅威の防止」→「保護の履歴」→ precheck.exe →「復元」または「デバイスで許可」。繰り返すなら「ウイルスと脅威の防止の設定」→「除外」にフォルダを追加。
  - 現在の配布版は誤検出されにくい形（普通の publish、製品情報付き、PowerShell 不使用）に変えてある。
- 「Windows によって PC が保護されました」→「詳細情報」→「実行」。自作の exe なので署名が無い。
- `.playwright` フォルダ（ブラウザ操作のドライバ）は隠しフォルダ扱い。GitHub Actions の成果物に入れるにはワークフローの `include-hidden-files: true` が必要（設定済み）。無いと起動時に「Driver not found」で止まる。
- 「ブラウザ「msedge」を起動できませんでした」→ Edge が入っているか確認。Chrome なら `config.json` の `"browser"` を `"chrome"` に。
- Wakumy の画面が変わって動かなくなった → `state\debug_*.png` と `state\debug_day_*.txt`（患者情報を含む）を名前を隠して開発者に見せる。実行時に AI は不要だが、直すときだけ Claude Code を使う。
- パスワードを変えた → `setup.bat` をもう一度。
