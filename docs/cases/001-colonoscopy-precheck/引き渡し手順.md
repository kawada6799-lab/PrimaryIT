# 案件001 引き渡し手順（クリニックのPCに入れる）

## 渡すもの

- GitHub の **Code → Download ZIP** で取得した ZIP。USB メモリやメール添付で渡す。
- 開発で使っていたフォルダを**そのままコピーしない**。次が入っているため。
  - `.venv`：作ったPCのパスに結びついていて、別のPCでは動かない
  - `local`：Wakumy のパスワード
  - `state`、`結果`：患者情報を含む履歴・結果ファイル
- Python 本体は ZIP に含まれない。クリニックのPCに別途インストールする。

## クリニックのPCでやること（15 分程度）

1. Python を https://www.python.org/downloads/ からインストール。インストーラの最初の画面で **「Add python.exe to PATH」にチェック**。
2. ZIP を展開し、`cases\001-colonoscopy-precheck` を開く。
3. `config.toml` の `[wakumy] id` が、そのクリニックで使うログインIDか確認する。違えば書き換える。
4. **`setup.bat` をダブルクリック**。必要な部品の取得とブラウザのダウンロードが自動で走る（インターネット必須）。最後に Wakumy のパスワードを聞かれるので入力。
5. **`動作確認.bat` → Enter** で 1 回流し、結果の一覧が出ることを確認。数分かかる。
6. タスクスケジューラに `run.bat` を登録する（`cases/001-colonoscopy-precheck/README.md` の「定期実行」参照）。4 日に 1 回の想定。
7. 看護師も結果を見るなら、`config.toml` の `[notify] output_dir` を院内の共有フォルダに変える。

## 困ったとき

- `setup.bat` が「Python が見つかりません」と言う → 手順 1 をやり直し、黒い画面を一度閉じてから再実行。
- Wakumy の画面が変わって動かなくなった → 黒い画面のエラー文と `state\debug_*.png` を開発者（Claude Code を使う人）に見せる。実行時に AI は不要だが、直すときだけ Claude Code を使う。
- パスワードを変えた → `setup.bat` をもう一度実行するか、`local\wakumy_password.txt` を書き換える。
