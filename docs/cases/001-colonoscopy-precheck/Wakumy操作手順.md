# Wakumy 医療機関管理画面 操作手順（先生からの聞き取り）

※ 認証情報は `local/wakumy.env`（git 管理外）。この文書には書かない。
※ 画面に映る患者名・診察券番号・メールアドレスはこの文書に書かない。

## ① ログイン

- URL: `https://hospital.wakumy.lyd.inc/a/admin-app/#/signIn`
- 「医療機関ログイン」画面。入力欄は **ID**（メールアドレス形式）と **パスワード**。ボタンは **ログイン**。
- ログイン後は管理画面トップ（予約一覧の日表示）に遷移する。

## ② ヘッダー右端の「≡」（三本線）ドロップダウンを開く

- ヘッダーのナビ：`予約一覧` `受付一覧` `患者管理` `FAQ` `設定` と、その右に `≡▾` ボタン。
- 開くと `予約通知` / `患者画面（院外）` / `ログアウト` の3項目。

## ③ 「予約通知」を押す

- DOM 上は `button.dropdown-item[role="menuitem"]` でテキストが `予約通知`。
- 「予約通知一覧」画面に遷移する。

## ④ 通知種別が「予約確定時」の行を見て、患者名を控える

予約通知一覧の構造：

- 検索条件：`予約ID`、`診察券番号`、`表示対象ステータス`（全て / 未通知 / 通知済 / 通知中止）、`検索` ボタン、`詳細検索` ボタン。
- 一覧の列：

| 列 | 内容の例（形式） |
|---|---|
| 予約 | `12345678 (姓 名)` ＝ 予約ID と患者名 |
| 通知種別 | `予約確定時`、`Web問診依頼（予約時 及び 予…）` など |
| 通知予定日時 | `即時` など |
| 通知完了日時 | `YYYY/MM/DD HH:MM:SS` |
| 通知方法 | `Eメール` などのバッジ |
| 通知中止の理由 | 空欄が多い |
| 通知先 | 患者のメールアドレス等 |

- 同じ予約IDに対して複数行（予約確定時／Web問診依頼）が並ぶ。**予約確定時** の行だけを対象にする。
- この画面には **予約メニュー（大腸内視鏡かどうか）は出ない**。予約IDか患者名で予約の中身を別途確認する必要がある（⑤以降で確認）。

## ⑤ ヘッダーの「患者管理」を押す

- 「患者一覧　全 N 名」画面。右上に検索ボックス（虫眼鏡アイコン）、`詳細検索`、`＋ 新規患者追加`。
- 一覧の列：`診察券番号` `姓` `名` `セイ` `メイ` `生年月日`（和暦 `S49.08.12` 形式） `性別` `予約作成`（「この患者で予約を取得」ボタン） `電話番号` `メールアドレス` `郵便番号` `住所`。

## ⑥ 検索ボックスに患者名（「姓 名」）を貼り付けて Enter

- 一覧がその患者だけに絞られる。部分一致のため、同姓同名や似た名前が複数出ることがある。

## ⑦ 該当患者の行をクリック

- 患者ページに遷移。左に「患者情報」パネル（`診察券番号` `氏名` `氏名（カナ）` `電話番号` `メールアドレス` `生年月日` `性別` `郵便番号` `住所` `メモ`）、右に「予約一覧」。
- 右上に `← 患者管理`（戻る）と `＋ この患者で予約を取得`。

## ⑧ 予約一覧で大腸検査の予約を確認

予約一覧の列：

| 列 | 値の例（形式） |
|---|---|
| ステータス | `予約`（赤）/ `来院`（橙）/ `患者都合キャンセル`（灰） |
| 予約日時 | `2026/10/31 (土) 14:00 ～ 14:30` |
| 診療科目 | `外来診察` / `内視鏡` |
| 予約メニュー | `胃＋大腸カメラ検査` `胃カメラ検査` `大腸カメラ事前診察` `外来診察初診` `外来診察再診` `連鎖用（内視鏡）` `連鎖用(胃+大腸)` |
| 予約メモ | 自由記述 |
| 予約票用メッセージ | 自由記述 |

- 下部に `全 10 件中 1 - 10 件目` のページ表示。
- **連鎖予約**の仕組みで、検査1件につき `連鎖用（内視鏡）`（外来診察）と `連鎖用(胃+大腸)`（内視鏡）の枠確保行が同時刻に並ぶ。これらは検査本体ではないので判定から除外する。

## ⑨ 「胃＋大腸カメラ検査」または「大腸カメラ検査」があるとき、「大腸カメラ事前診察」の予約があるか確認

- 事前診察は `外来診察` 科目で、検査日より前（例：10/31 の検査に対し 10/9）。
- プログラムでは「検査日の前 30 日以内に、ステータスが 予約 または 来院 の事前診察があれば OK」とした。

## ⑩ 無ければ院長または看護師が電話連絡する

- ここをプログラムでは「指定メールアドレスへ『〇〇さん 大腸カメラ事前診察の予約なし』のメールを送る」に置き換える。
- 同じ患者・同じ検査日には 1 回だけ送る。

## 画面の技術的な特徴（開発メモ）

- Vue.js + BootstrapVue 製の SPA（`data-v-*` 属性、`__BV_dropdown__`）。URL はハッシュルーティング（`#/signIn` など）。
- SPA なので、裏で JSON API を呼んでいる可能性が高い。Playwright で画面を操作しつつ、
  予約通知一覧・予約一覧を返す XHR の応答を横取りできれば、DOM を読むより安定する。
  → ログイン後に DevTools の Network タブ（Fetch/XHR）で、予約通知一覧を開いたときのリクエスト URL と応答 JSON を確認したい。
- 予約一覧画面：診療科タブ（すべて / 外来診察 / 発熱外来 / **内視鏡** / 健診・人間ドック / 自由診療 / インフルエンザワクチン …）、日表示 / 週表示 / 月表示。
  列は `ステータス・来院時刻` `予約番号` `診察券番号・生年月日(年齢)` `患者名` `予約メニュー` `予約/患者メモ` `問診メモ`。
