# 判定コメントマスター（業者の「判定コメント名称（印字内容）」3 ページ分、2026-11-04 転記）

結果のお知らせの「判定コメント」欄に印字される定型文のコード表。先生は受診票の判定コメント欄にこのコードを書く。
丸印（①②③）は先生がよく使うとして現物に印を付けていたもの。実際の結果のお知らせの判定コメントは「C006 + H403」の 2 行だった。

分類は総合判定の区分と対応しているとみられる（H0=異常なし、H1=有所見健康、H2=要受診、H3=要再検査、H4=要経過観察、H5=要精密検査、H6=要治療、H7=要継続治療）。
C コードは生活習慣の助言で、区分に関係なく付ける。

**注意**：受診票の各項目の判定欄に書く数字コード（150、180 など）はこの表とは別の「判定区分マスター」。所見コード（V014、0008 など）も別の「所見マスター」。どちらも未入手。

## プログラムでの使い方（案）

- 総合判定の区分が決まれば H コードは既定値を自動で入れられる（例：異常なし → H001、要経過観察 → H403、要継続治療 → H701）。先生は一覧から変えるだけ。
- C コードは問診と計測から自動で候補を出せる（喫煙あり → C017、BMI 25 以上 → C018、飲酒が多い → C016、既定 → C006）。
- 総合判定の区分そのものは「各項目の判定区分のうち最も重いもの」で決めるのが基本。判定区分マスター（150、180 など）を入手したら、その順序を設定ファイルに持つ。
