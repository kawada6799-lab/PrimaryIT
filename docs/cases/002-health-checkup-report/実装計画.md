## 作るものの形

- 置き場所：`cases/002-health-checkup-report-cs/`（C# .NET 8、self-contained のフォルダ 1 つ。技術方針どおり単一 exe にしない）。
- 1 つの exe の中に：PC の画面（WPF）、タブレット向け入力ページを配る小さな Web サーバー（ASP.NET Core / Kestrel、専用 Wi-Fi 側のアドレスにだけ待ち受け）、判定ロジック、PDF 生成、SQLite（SQLCipher 暗号化）。
- 設定はフォルダ内のファイル：`config.json`（取込フォルダ、バックアップ先、待ち受けアドレス、PIN、音声の有効／無効）、`判定基準.json`、`判定区分.csv`、`所見マスター.csv`、`判定コメント.csv`、`コース.json`。マスターの実物が届いたら差し替える。
- 配布は GitHub Actions でビルド（案件001 と同じ形）。

## 使う部品（候補。理由付き）

| 用途 | 部品 | 理由 |
|---|---|---|
| PC 画面 | WPF | Windows 標準。タッチ対応。配布フォルダに追加物不要 |
| 入力ページ | ASP.NET Core（Kestrel）を exe 内に同居、ページは素の HTML＋JS | タブレット側に何も入れない。ライブラリ追加を最小に |
| DB | Microsoft.Data.Sqlite ＋ SQLCipher バンドル | ファイル 1 つ。暗号化は接続文字列で有効化 |
| PDF 生成 | QuestPDF（A3／A4 の帳票）。日本語フォントは Windows 標準の游ゴシックか IPA フォントを同梱 | 表組みの帳票が書きやすい。ライセンスは年商 100 万ドル未満の組織は無償（クリニックは該当）。問題があれば PdfSharp に切替 |
| PDF 読み取り | PdfPig | 文字抽出のみ。スクリプト等を実行しない |
| 音声認識 | vosk-browser（WASM）＋ vosk-model-small-ja | オフライン、ブラウザ内で完結、限定語彙に対応 |
| QR 生成 | QRCoder | 受診票の QR |
| テスト | xUnit | 判定ロジックと読み取りは必ずテストを書く |

## 作り方のルール（このケース固有）

- 判定ロジックは設定ファイル駆動。コードに数値の閾値を書かない。
- すべての判定に「自動／手動」と変更時刻を持たせる。
- ログ・テスト・モックに実在の患者情報を入れない。架空データは `tests/` に置く。
- 外向きの HTTP クライアントを使わない（CI で参照を検査）。Kestrel の待ち受けは設定したアドレスのみ。
