# 判定区分マスター・所見マスター（仮。現物のマスターは未入手。推測を含む）

**このファイルは推測です。** 受診票の手書きと結果のお知らせの印字を突き合わせて分かった範囲だけが「確実」、それ以外は「推測」と書く。
ファルコのマスターが届いたら、このファイルを実物で置き換える。プログラム側はコードを設定ファイルで持つので、実物に合わせて設定を直せば済むように作る。

## 1. 判定区分コード（受診票の各項目の「判定」欄に書く 3 桁の数字）

| コード | 区分 | 根拠 |
|---|---|---|
| 150 | 異常なし | **確実**。計測・視力・聴力・血圧・尿・胸部 X 線・心電図・診察所見の判定欄に 150 と書かれ、結果のお知らせで「異常なし」になっている |
| 180 | 要経過観察 | **確実**。胃内視鏡（胃ポリープ・逆流性食道炎）と大腸内視鏡の判定欄に 180 と書かれ、結果のお知らせで「要経過観察」になっている |
| 160、170 | 有所見健康／要受診／要再検査 のどれか | **推測**。150 と 180 の間に 2 つ入る。判定コメントの分類順（異常なし→有所見健康→要受診→要再検査→要経過観察）と一致しない可能性があるので、実物で確認 |
| 190 以降 | 要精密検査、要治療、要継続治療 | **推測**。10 刻みで続くと仮定 |

結果のお知らせに出る区分の文字は、判定コメントマスターの分類と同じ 8 種類とみられる：
**異常なし／有所見健康／要受診／要再検査／要経過観察／要精密検査／要治療／要継続治療**。
計測の判定には「正常範囲」という別の文字も出る（BMI の判定）。

### 重さの順（総合判定を決めるときの順。推測）

軽い → 重い：異常なし ＜ 有所見健康 ＜ 要経過観察 ＜ 要再検査 ＜ 要受診 ＜ 要精密検査 ＜ 要治療 ＜ 要継続治療（治療中は別扱い）

総合判定は「各項目の区分のうち最も重いもの」を基本にし、先生が変えられるようにする。
「要継続治療」は問診で治療中と分かった項目に付ける区分で、重さの順に並べるものではないかもしれない。実物で確認。

## 2. 所見コード（受診票の「所見」欄に書く英数字）

| コード | 意味 | 根拠 |
|---|---|---|
| V014、V016 | 胃内視鏡の所見。「胃ポリープ」「逆流性食道炎」のどちらか | **ほぼ確実**（受診票の胃の行に V014・V016、結果のお知らせの胃内視鏡所見に「胃ポリープ」「逆流性食道炎」）。どちらがどちらかは未確認 |
| 0008、0018 | 大腸内視鏡の所見 | **確実に大腸の所見コード**。中身は未確認（大腸ポリープ、憩室などと推測） |
| 胸部 X 線・心電図・診察所見に書かれた走り書き | 「異常なし」を表す定型コード（9999 のような番号か、略号） | **推測**。結果のお知らせでは「異常を認めず」「正常範囲」と印字される |

推測されるマスターの構造：**部位（検査）ごとに所見コードの表がある**（胸部 X 線用、心電図用、診察所見用、胃内視鏡用、大腸内視鏡用）。
コードの頭文字で部位を表している可能性がある（V = 上部消化管？）。所見コードから判定区分が自動で決まる対応表（例：胃ポリープ → 要経過観察）もマスター側にあるとみられる。

## 4. 血液検査の判定（結果のお知らせでは「血液検査判定」として分野ごとに印字）

分野：肝機能、腎機能、脂質、糖機能、膵機能、血液一般、血清学。
確認できた規則：**分野内に基準値を外れた項目が 1 つでもあれば「要経過観察」**（脂質：総コレステロール 224 と HDL 99 が基準値外 → 要経過観察）。
基準値を大きく外れたときに「要再検査」「要精密検査」「要治療」に上がる閾値があるはずだが、未確認。先生の基準で設定ファイルに持つ。

基準値はファルコの報告書に印字されるものと同じ（性別で異なる項目あり：赤血球数、ヘモグロビン、ヘマトクリット、クレアチニン、尿酸、γ-GTP、HDL）。

## 5. メタボリックシンドローム判定（特定健診の標準。確実度は高い）

- 腹囲：男性 85cm 以上、女性 90cm 以上
- 血圧：収縮期 130 以上 または 拡張期 85 以上（または降圧剤服用）
- 脂質：中性脂肪 150 以上 または HDL 40 未満（または服薬）
- 血糖：空腹時血糖 110 以上 または HbA1c 6.0 以上（または服薬）

腹囲が基準以上で、血圧・脂質・血糖のうち 2 つ以上 → 該当。1 つ → 予備群。腹囲が基準未満 → 非該当。
結果のお知らせのコメント「4 つの診断基準の全てが正常範囲内」はこの 4 つを指す。
