# 判定区分マスター（実物、2026-11-06 入手）・所見マスター（仮）

## 1. 判定区分コード（「（標準）判定表示一覧表」より。実物）

受診票の各項目の「判定」欄に書く入力コード。判定ランクは重さ（小さいほど重い）。プログラムは `config/判定区分.csv` に持ち、`rank` の大きい方が重い。

| 入力コード | 略称 | 名称 | 判定ランク | プログラムの rank |
|---|---|---|---|---|
| 150 | 正常 | 異常なし | 150 | 1 |
| 155 | 有所 | 有所見健康 | 145 | 2 |
| 170 | 再検 | 要再検査 | 130 | 3 |
| 175 | 食療 | 要食事療法 | 125 | 4 |
| 180 | 経過 | 要経過観察 | 120 | 5 |
| 185 | 精密 | 要精密検査 | 115 | 6 |
| 190 | 治療 | 要治療 | 110 | 7 |
| 195 | 継続 | 要継続治療 | 105 | 8 |

総合判定は「各項目の区分のうち判定ランクが最も重いもの」。先生が変えられる。
「要受診」は判定コメント（H201・H202）の分類にはあるが、判定区分には無い。仮で使っていた 160・190（要受診）・200・210・220 は上の実物に置き換えた（尿の（+）などの「要受診」は 185 要精密検査 に寄せた。仮）。

### 項目ごとの個別コード（番号が共通の区分と被る）

| 項目 | コード | 名称 | 総合判定に数えるときの区分（仮） |
|---|---|---|---|
| 計測（肥満度 BMI） | 130 | 痩せ過ぎ | 180 要経過観察 |
| | 145 | 痩せ気味 | 155 有所見健康 |
| | 150 | 正常範囲 | 150 |
| | 155 | 太り気味 | 155 有所見健康 |
| | 170 | 太り過ぎ | 180 要経過観察 |
| 視力 | 125 | 視力再矯正 | 155 |
| | 130 | 視力矯正 | 155 |
| | 145 | 眼鏡あり | 150 |
| | 150 | 異常なし | 150 |

同じ番号でも項目によって意味が違う（計測の 170 は太り過ぎ、尿の 170 は要再検査）ので、`判定区分.csv` の `section` 列で区別し、`overall` 列で総合判定に数えるときの共通区分を決める。
BMI の境界（痩せ過ぎ <17、痩せ気味 17〜18.49、太り気味 25〜29.99、太り過ぎ 30〜）と視力の規則（裸眼で両眼 0.5 以上 → 異常なし、矯正で見える → 眼鏡あり、矯正しても見えない → 視力再矯正、裸眼で見えず矯正なし → 視力矯正）は仮。`config/判定基準.json`。

## 2. 所見コード（実物、2026-11-06 入手。Excel 2 冊）

| 部位 | コードの形 | 件数 | 例 |
|---|---|---|---|
| 大腸内視鏡 | 4 桁の数字 | 52 | 0002 ポリープ、0018 内痔核、9998 所見なし、9999 異常を認めず |
| 胃内視鏡 | U＋3 桁 | 271 | U004 胃ポリープ、U016 逆流性食道炎、U013 萎縮性胃炎、9998 所見なし |
| 胸部X線 | D＋3 桁などの一覧（2,231 件）と、**組み合わせコード**（位置 1 文字＋部位 1 文字＋所見 2 文字） | 2,231 ＋ 組み合わせ | A001 右肺野異常陰影、B303 左中肺野石灰化影、C259 両上肺野円形陰影 |
| 心電図 | 4 桁の数字 | 851 | 0010 洞性徐脈、0008 不完全右脚ブロック、9987 正常範囲内 |
| 診察所見 | 4 桁の数字 | 1,883 | 0022 心雑音、0209 心音異常なし |

- 同じ番号が部位ごとに別の意味（0001 は大腸内視鏡ではポリープの疑い、心電図では狭心症）。プログラムは（部位、コード）の組で持つ。
- 胸部X線の組み合わせコードは `config/胸部X線所見部品.csv`（位置 A右／B左／C両、部位 0肺野／1肺尖部／2上肺野／3中肺野／4下肺野／5肺門部、所見 01〜K7 の 319 件）から作る。画面では 3 つ選んで追加する。
- **実物のマスターには判定が付いていない**（紙では先生が判定コードを別に書く）。プログラムは、名称が「異常なし」「所見なし」「正常」などなら 150、それ以外の所見があれば**仮に 180 要経過観察**を付け、先生が画面で変える（`config/判定基準.json` の `findings`）。特定の所見に判定を固定したければ `config/所見マスター.csv` の `judgment` 列に書く。
- 胃部X線・腹部エコーは実物が無いので仮の数行のまま。
- 受診票に手書きされていた「V014」「V016」は、マスターでは U014 びらん性胃炎・U016 逆流性食道炎（U を V と読んだ可能性）。
