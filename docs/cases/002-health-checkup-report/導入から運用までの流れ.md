# 案件002 導入から運用までの流れ（ダウンロード → 初回設定 → 健診当日 → 採血結果 → 先生の確認 → 印刷・郵送 → 更新）

2026-11-06 の先生の決定（ネットにつながず全部ローカル、写真で取り込む、先生は所見とコメントだけ見る、印刷は USB のプリンター）に沿って、
**誰が・いつ・どの画面で何をするか**を時系列で書いたものです。細かい設定の説明は `cases/002-health-checkup-report-cs/README.md` にあります。

登場する機器は 3 つだけです。

| 機器 | 役割 | インターネット |
|---|---|---|
| 院所有の PC（Windows） | プログラム本体。データ（暗号化 DB）もここだけ | つながない |
| 携帯（iPhone でも Android でも可。私物でも可） | 入力シートと採血の報告書を撮って PC へ送るだけ。写真は携帯に残らない | 専用 Wi-Fi のみ（インターネット無し） |
| プリンター（複合機） | 受診票・結果のお知らせ・検査内容の説明を印刷 | PC と USB 直結 |

受診者 1 人の状態は **入力中 → 判定済 → 確定 → 郵送済** と進みます（画面右上のバッジ）。

## 0. ダウンロード（インターネットにつながる手元の PC で。初回だけ zip を手で取る）

1. GitHub の `PrimaryIT` → **Actions** → 左の **build-002-cs** → 一番上の実行（緑のチェック）を開く。
2. 下の **Artifacts** の `kenshin-002-windows` をクリックしてダウンロード（zip、150MB 前後。プログラム・.NET ランタイム・写真読み取りのモデルが全部入り）。
3. zip を展開し、できたフォルダ（例：`kenshin`）を USB に入れる。

2 回目以降は zip を手で取りません（→ **7. 更新**）。

## 1. 院所有 PC に置く・初回設定（初回だけ、15 分）

1. フォルダを消されない場所に置く（例：`C:\kenshin`）。インストールは不要。
2. ウイルス対策（Norton など）に止められたら「復元して除外」（README の「初回だけ：ウイルス対策」）。
3. `config\config.json` をメモ帳で開いて直す。
   - `clinic.name`・`clinic.doctor`（結果のお知らせに印字する実施医師名）・`clinic.occupationalDoctor`（産業医名、無ければ空）
   - `pin`：携帯から開くときの PIN（4〜6 桁）
   - `listen.lanAddress`：専用 Wi-Fi 側の PC の固定 IP（例 `192.168.50.1`）
   - `backupDir`：終了時に DB をコピーする先（例 `E:/kenshin-backup`。外付け SSD か USB メモリ）
   - **パスの `\` は JSON では 2 つ重ねて `\\` と書くか、`/` にする**（`"C:\Users\..."` のように 1 つだと起動時に「○行目を読めません」で止まる）
4. **`make-shortcut.bat` を 1 回ダブルクリック** → デスクトップに「健診結果作成」のアイコンができる。
5. アイコンをダブルクリック → Edge がアプリの窓（アドレスバー無し）で開く → **起動パスワードを決めて入力**。
   これがデータの暗号鍵。忘れると開けないので紙に書いて金庫へ。
6. 専用 Wi-Fi を用意する：トラベルルーターをアクセスポイントにし、WAN は何もつながない。PC（固定 IP、ゲートウェイ無し）と携帯だけをつなぐ（WPA2 のパスワード）。
7. 携帯のブラウザで `https://<lanAddress>:5443/` を開き、PIN を入れる。初回は `http://<lanAddress>:5080/ca.crt` から証明書を入れる（iPhone：ダウンロード → 設定 → 一般 → VPN とデバイス管理 → インストール → 設定 → 一般 → 情報 → 証明書信頼設定で有効）。
   証明書を入れなくても `http://<lanAddress>:5080/` で使えます（「撮る」で端末のカメラアプリが開く。ガイド枠は出ない）。
8. プリンターを PC に USB でつなぎ、Windows の「プリンターとスキャナー」に出ることを確認。

設定の確認：画面右上に「v0.1.0.0（ビルドの日時）」が出て、赤い帯（ネットワーク接続の警告）が出ていなければ OK。

### `listen.lanAddress` とは（携帯から PC を呼ぶための住所）

- プログラムは PC の中（`127.0.0.1`）でしか待ち受けないのが既定です。携帯から開くには「PC が Wi-Fi 側で持っている IP アドレス」でも待ち受ける必要があり、それを書くのが `lanAddress` です。携帯はその IP を打って開きます（`http://<lanAddress>:5080/`）。
- PC の IP は **コマンドプロンプトで `ipconfig`** → 使っている Wi-Fi（または有線）アダプターの **IPv4 アドレス**（例 `192.168.11.5`）。
- 「固定」と書いたのは、IP が変わると携帯のブックマークと証明書が合わなくなるためです。院では Windows のアダプター設定で IP を手で決めるか、トラベルルーターの DHCP で PC に同じ IP を割り当てます（インターネット無しなので、デフォルトゲートウェイは空のままでよい。空だから起動チェックも通る）。

### 自宅のノート PC で先にテストしたいとき（家の Wi-Fi のまま）

家の Wi-Fi はインターネットにつながっている（＝ゲートウェイがある）ので、そのままでは起動チェックに止められます（画面に「停止中」、API は 423）。テストの間だけ外します。

1. `ipconfig` で PC の IPv4 アドレスを見る（例 `192.168.11.5`）。
2. `config\config.json` を直す：`"lanAddress": "192.168.11.5"`、`"networkGuard": false`（テスト中は赤い帯「開発用」が出る）。
3. アイコンから起動。初回に Windows のファイアウォールが「dotnet.exe のアクセスを許可しますか」と聞いたら **プライベート ネットワークで許可**。
   聞かれず携帯から開けないときは、Windows の 設定 → ネットワークとインターネット → その Wi-Fi → **ネットワーク プロファイルを「プライベート」** にし、
   ファイアウォールで `runtime\dotnet.exe` の受信を許可する（または TCP 5080・5443 の受信規則を足す）。
4. 携帯を同じ家の Wi-Fi につなぎ、ブラウザで `http://192.168.11.5:5080/` → PIN（`config.json` の `pin`、既定 1234）。
   カメラのガイド枠まで試すなら `http://192.168.11.5:5080/ca.crt` で証明書を入れてから `https://192.168.11.5:5443/`。
5. **テストは架空の受診者だけ**で行う（本物の患者情報は家の Wi-Fi 上の PC に入れない）。
6. 院に持ち込むときは `"networkGuard": true` に戻し、`lanAddress` を専用 Wi-Fi 側の IP に書き換える。家の Wi-Fi の IP は DHCP で変わることがあるので、携帯から開けなくなったら `ipconfig` で見直す。

## 2. 健診当日：受付（PC、1 人 1 分）

1. アイコンから起動（既に動いていれば画面が開くだけ）。
2. 左の **「＋ 受診者」**。2 回目以降の人は「既存から探す」に氏名・カナ・ID のどれかを入れて選ぶ（前回・前々回の値が結果のお知らせに自動で載る）。
   初めての人は 氏名・カナ・性別・生年月日・個人ID（ファルコ）・診察券番号・（企業健診なら 社員番号・事業所・所属）を入れる。
3. **健診実施日** と **コース**（企業健診・人間ドックなど）を選んで登録。
4. 画面下の **「入力シートを印刷」** → A4 1 枚（受診者名・個人 ID・QR・健診回の番号入り。コースにある検査だけが載る）。受診票（問診票）と一緒に受診者の綴りに挟む。

## 3. 健診当日：看護師の記入と撮影（紙 → 携帯、1 人 2 分）

1. 計測・視力・聴力・血圧・尿・便・食後時間を **入力シート** に書く。
   - 数字は **1 マスに 1 文字**（右詰め。小数点は印字済み）。
   - 選択は **□ を黒く塗る**（✓ や ○ ではなく塗りつぶし）。
   - 判定は書かない（プログラムが付ける）。問診は受診票の裏に受診者が書く（紙のまま。画面には先生が所見を入れる）。
2. 携帯で入力ページを開き、受診者を選び、「計測・検査」タブの **「📷 入力シートを撮る」**。
   - ガイド枠に用紙全体を入れ、四隅の黒い四角と QR を隠さず、影を入れず真上から。暗い・ぼけは撮った直後に注意が出るので撮り直す。
3. 10〜20 秒で **確認画面**。緑は読めたもの、**赤（要確認）** は写真の切り抜きと紙を見比べて直す（薄い塗り・2 つ塗り・範囲外の数字など）。
4. **「この内容で保存」** → 値が入り、判定（計測・視力・血圧・尿・便）が付く。状態は 入力中 のまま（採血待ち）。
   - シートの健診回の番号を読んで受診者を突き合わせるので、別人のシートなら警告が出る。
   - 携帯が無いとき・読めないときは PC の同じタブに手で打てる。

## 4. 採血の報告書が届いたら（看護師、1 人 2 枚、3 分）

ファルコからの紙の報告書（1/2・2/2）を撮ります。電カルにも PHC の PC にもファルコの PC にも触れません。

1. 受診者を開き「血液検査」タブの **「📷 報告書を撮る／写真を選ぶ」**。用紙全体が入り、左右 2 枚の表が隠れないように真上から撮る。
2. **確認画面**：報告書には同じ値が左右に 2 回印字されているので、両方読んで一致し桁も妥当なものは **緑**。食い違い・片方だけ・陽性（＋）・桁が怪しいものは **赤（要確認）** → 切り抜きと紙を見比べて直す。
   読み取った氏名カナ・個人 ID・採取日と、いまの受診者が一致しているかも出る。
3. **「この内容で保存」**。2 枚目も同じ（同じ項目は上書き、ほかは残る）。保存した写真は `取込\済\` へ。
4. 全項目がそろうと分野別の血液判定・メタボ判定が付き、状態が **判定済** になる。

項目の少ない健診でも枠は同じ 46 項目で、値の無い枠は画面も印字も空欄です。

## 5. 先生の確認（PC、1 人 1〜2 分）

自動判定の一覧は見なくてよい（折りたたんである）。

1. 左の一覧（当日）か「未完了一覧（過去 90 日）」から受診者を開く。
2. **「所見」タブ**：胸部X線・心電図・内視鏡・診察所見などを所見マスターから選ぶ（検索で絞る。胸部X線は位置＋部位＋所見の組み合わせも可。異常なしは「所見なし（異常なし）で入れる」）。
3. **「総合判定・印刷」タブ**：上から順に
   1. **所見**（いま入れたもの）
   2. **自動で入ったコメント**：H（判定コメント）と C（生活指導）が総合判定に合わせて入っている。違えば選び直し、必要なら「追加コメント」に書き足す。
   3. **「問題なければ保存（確定）」** → 状態が **確定** になり、結果のお知らせの PDF が `data\pdf\` に保存される。未入力の必須項目があれば警告が出る（そのまま確定もできる）。
4. 確定後に直したいときは「確定を解除」してから直す。

## 6. 印刷と郵送（事務、1 人 1 分）

1. 「総合判定・印刷」タブの **「3 種まとめて印刷（受診票＋結果のお知らせ＋説明）」** → Edge に PDF が開く → 印刷（USB のプリンター）。
   結果のお知らせだけ・検査内容の説明だけ も押せる。
2. 封入して郵送したら **「郵送済にする」**。
3. 「要受診・要再検査・要精密検査・要治療の人（過去 1 年）」の一覧で、フォローが要る人を追える。

## 7. 一日の終わり

- 画面右上の **「終了」**（PC の画面にだけ出る）→ `backupDir` に DB をコピーしてから止まる。アプリの窓を × で閉じただけでは動いたまま（次にアイコンを押せば画面が戻る）。
- 携帯の専用 Wi-Fi は切ってよい。写真は携帯に残っていない。

## 8. 更新（細かい修正が入ったとき。zip を手で取らない）

| どこで | やること |
|---|---|
| インターネットにつながる手元の PC | 配布フォルダの **`update-from-github.bat`** をダブルクリック。最新ビルドを取って入れ替え、起動し直す。初回だけ GitHub のトークンを貼る（Fine-grained token：Repository access は PrimaryIT だけ、Permissions は Actions: Read-only。`local\github-token.txt` に保存される） |
| 院所有 PC（インターネット無し） | 手元の PC で **`make-update-usb.bat`** → `kenshin-update.zip` を USB に入れる → 院所有 PC の **`apply-update.bat`** をダブルクリック（zip は USB のルートに置いたままでよい） |

- 残るもの：`data\`（DB・発行 PDF・証明書）、`config\config.json`、`取込\`、`local\`。
- 上書きされるもの：プログラム、ランタイム、画面、フォント、OCR のモデル、`config\` のマスター（判定基準・判定区分・所見・コメント・血液項目・コース）。前の `config\` は `backup\config-<日時>\` に残る。
- 更新できたかは画面右上の「v0.1.0.0（日時）」が新しくなっていれば OK。

## 9. 困ったとき

| 症状 | 見るところ |
|---|---|
| アイコンを押しても画面が開かない | 手で `http://127.0.0.1:5080/` を開く。黒い窓（タスクバーの kenshin）にエラーが出ていないか。ウイルス対策に止められていないか |
| 起動時に赤い帯「ネットワーク接続」 | PC がゲートウェイのあるネットワーク（院内 LAN・インターネット）につながっている。専用 Wi-Fi だけにする |
| 携帯から開けない | 携帯が専用 Wi-Fi につながっているか、`listen.lanAddress` が PC の IP と同じか |
| 写真を送ってもすべて赤（要確認） | 四隅の印（入力シート）か表の左右 2 枚（報告書）が隠れている・影・ぼけ。撮り直す。`models\ocr\` が無いと読み取りは動かない（画面右上の状態に出る） |
| 起動パスワードを忘れた | 開けない（暗号鍵そのもの）。`backupDir` のコピーも同じ鍵。金庫の紙を見る |
| 結果のお知らせの判定や文言を直したい | `config\判定基準.json`・`判定区分.csv`・`判定コメント.csv`・`所見マスター.csv`（README「設定の変え方」） |

## 先生に決めてもらうこと（仮のままの規則）

- 所見ありの部位の判定の既定（いま 180 要経過観察）、尿（+）→ 185、脂質・糖の 175 要食事療法 の扱い。
- 肥満度（BMI）と視力の個別コードを総合判定にどう数えるか。
- 女性の血液の基準値（女性の報告書が届いたら）。
- 印刷した入力シートに実際に手書きして撮ったときの読み取り率（確認画面の赤の数）。
