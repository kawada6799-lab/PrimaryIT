# 案件002：健康診断の入力・自動判定・結果のお知らせ作成（要件の下書き）

状態：**下書き（2026-11-04）**。先生のヒアリングと紙の現物から起こした。判定区分マスター・所見マスターは未入手のため、該当部分は仮。
調査の経緯は `調査計画.md`、コード表は `判定コメントマスター.md`・`判定区分・所見マスター（仮）.md`。

## 困っている人と場面

- **誰が**：院長（判定・所見の記入）、看護師（計測値の手書き）、事務（郵送）
- **何が**：健診のたびに受診票へ手書きし、判定コードを手で付け、ファルコに送って A3 の結果のお知らせが戻るのを待ち、説明の紙を同梱して郵送している。手書き・手計算（BMI）・コードの暗記・往復の待ち時間がある。
- **今の対応**：ファルコの健診サービスに受診票を送って結果のお知らせを作ってもらっている。

## やりたいこと

院内の PC で次を完結させる。

1. 看護師が計測・視力・聴力・血圧・尿・便・問診を**入力**する（紙の受診票と同じ順）。
2. プログラムが BMI・腹囲・血圧・尿などの**判定区分を自動で付ける**。
3. 先生が胸部 X 線・心電図・診察所見・内視鏡の**所見を一覧から選ぶ**。所見から判定区分の案が入る。
4. ファルコの採血結果を**取り込み**、分野ごとの血液検査判定とメタボ判定を自動で付ける。
5. 総合判定と判定コメント（H コード＋C コード）の案を出し、**先生が確認・修正して確定**する。
6. 今の A3 と同じ見た目の**結果のお知らせを PDF で作って印刷**する（今回・前回・前々回の比較つき）。検査内容の説明の末尾（次回の胃カメラ・大腸カメラの年数）も印字。
7. 受診者ごとの履歴を院内に**保存**し、翌年の前回・前々回に使う。

段階は `調査計画.md` の「作るものの全体像」のとおり 3 段階に分け、第 1 段階（入力と自動判定、受診票の印字）から作る。

## 動かす場所

- **院所有の PC**（机に置く小型デスクトップかノート。プリンタのあるネットワークに有線でゲートウェイ無しで接続。インターネットへの経路なし。患者情報を扱う）。技術方針どおり C# (.NET 8) self-contained のフォルダ 1 つ、インストール不要、管理者権限不要。
- データは同じ PC（または院内の共有フォルダ）のファイル DB（SQLite）。インターネットには出さない。

## 実行時に AI は必要か

- **判定には不要。** 判定はすべて基準値との比較と対応表で決定的に決まる。判定コメントは定型文のコードを選ぶだけ。自由記述は先生が入力する。
- 音声入力だけは、タブレット内で動くオフラインの音声認識モデル（LLM ではない。外部送信なし）を使う。使う場所と理由を先生に説明済み。無効化できる。
- AI を使うのは開発時のみ。

## 入力の方法（2026-11-04 決定。詳細は `入力方法の検討.md`）

- **看護師は 1 万円前後の Android／Fire タブレットで入力する。** ブラウザで、机の院所有 PC が配る入力ページ（専用 Wi-Fi、PIN 付き）を開く。値は PC の DB に直接入る。タブレットにアプリもデータも置かない。
- 入力ページは受診票の並び、既定値＝正常、テンキー表示、範囲外はその場で警告。スマホでも開ける。
- 先生は机の PC の画面で所見を選び、確定・印刷する。PC の画面でも同じ入力ができる。
- PC とタブレットは専用 Wi-Fi（トラベルルーターをアクセスポイントに。インターネットにも院の網にもつながない）。
- **音声入力**（2026-11-04 先生の指示で第 1 段階に含める）：入力ページに、オフラインで動く限定語彙（数字・てん・つぎ・もどる・なし・あり・プラス・マイナス）の音声認識を付ける。タブレット内で完結し外に送らない。認識結果は欄に入れて人が確認してから保存。設定で無効化できる。
- 測定機器からの取り込みは行わない（費用の方針）。

## 入力（画面の項目）

受診票の並びに合わせる。単位・桁は受診票と結果のお知らせに合わせる。

| 区分 | 項目 |
|---|---|
| 受診者 | 個人 ID（ファルコの ID と院内の診察券番号の両方を持てる）、氏名、カナ、性別、生年月日、事業所・所属、健診実施日、食後時間（分） |
| 計測 | 身長、体重、腹囲 → 標準体重・肥満度・BMI は自動計算 |
| 視力 | 右裸眼、左裸眼、右矯正、左矯正 |
| 聴力 | 右 1000Hz、右 4000Hz、左 1000Hz、左 4000Hz（所見なし／あり）、会話法 |
| 血圧 | 1 回目 最高／最低、2 回目 最高／最低、降圧剤服用 |
| 尿 | 糖、蛋白、潜血（−／±／+／2+／3+）、ウロビリノーゲン（正常／+／−）、生理中 |
| 便 | 潜血 1 回目、2 回目（−／+） |
| 肺機能 | 肺活量、予測肺活量、肺活量比、努力肺活量、1 秒量、1 秒率（任意） |
| 所見 | 胸部 X 線（直接／間接、撮影日、所見コード複数）、胃部 X 線、心電図（負荷の有無）、診察所見、胃内視鏡、大腸内視鏡、その他（所見マスターから選択。自由記述も可） |
| 問診 | 受診票の裏面（服薬 3 種、既往歴、生活習慣）。メタボ判定と C コードの候補に使う |

## 判定のルール（設定ファイルで変更可）

- 数値項目の判定、血液検査の分野ごとの判定、メタボ判定、総合判定の決め方は `判定区分・所見マスター（仮）.md` を初期値にし、マスター入手後と先生の指示で直す。
- 血液の基準値は性別ごとに持つ。初期値はファルコの報告書の基準値。
- **血液検査の項目は固定の枠**（2026-11-06 先生）：ファルコの報告書の全 46 項目（肝機能 10、膵 1、脂質 4、電解質・鉄・CK 6、腎 4、糖 2、血清学 7、血液一般 8、腫瘍マーカー 4）を `config\血液項目.csv` に持ち、これが最大。項目の少ない健診でも枠は同じで、値の無い枠には数字を入れず空欄のまま（画面も結果のお知らせも）。取り込んだ項目名はマスターの名前に揃える（別名で吸収）。
- 総合判定は各項目の判定区分のうち最も重いものを案にする。先生が変えられる。
- 判定コメントの H コードは総合判定の区分から既定値を入れる（異常なし → H001、要経過観察 → H403、要継続治療 → H701。先生の丸印に合わせる）。C コードは問診と計測から候補（喫煙 → C017、BMI 25 以上 → C018、飲酒多い → C016、既定 → C006）。
- 判定を自動で付けた項目は、画面で「自動」と分かるようにし、先生が上書きしたものは「手動」と記録する。

## 出力

1. **受診票（A4）**：今の紙と同じ内容を印字。ファルコに送る必要がある間はこれを送る。
2. **結果のお知らせ（A3 二つ折り、PDF）**：表紙（事業所・氏名・生年月日・年齢・個人 ID・健診／人間ドック・今回／前回／前々回の実施日・実施医師名）、中面（身体計測〜血液検査判定の今回／前回／前々回、血液の全項目、所見と判定、判定コメント、メタボ判定とコメント）。
3. **検査内容の説明（A4 両面）**：固定の文面＋次回カメラの年数の印字。
4. 一覧：当日の受診者と判定の一覧（確認用）。

## 採血結果の取り込み（第 2 段階。2026-11-04 決定）

- **HR-f 端末で検査結果画面を Microsoft Print to PDF で印刷し、その PDF を暗号化 USB で院所有 PC へ運び、プログラムが指定フォルダから読み取る。**
- 院所有 PC はスタンドアロン（ネットワーク未接続）。詳細は `受け取り方法とセキュリティ.md`。
- PDF は文字 PDF であることが前提。画像 PDF だった場合は方式を見直す。
- 受診者との突合は個人 ID（ファルコの依頼に載る番号）または診察券番号。氏名・生年月日は補助。
- 取り込めないときは手入力もできるようにする（少数の項目なら現実的）。

## 保存するデータ

- 受診者（ID、氏名、カナ、性別、生年月日、事業所）
- 健診回（実施日、コース、入力値、所見、判定、判定コメント、確定日時、確定者）
- 設定（判定基準、コード表、帳票の文面）
- 過去データの初回取り込み：ファルコから過去 2 回分を CSV でもらえれば読み込む。もらえなければ最初の 2 年は前回・前々回が空欄になる。

## セキュリティ（2026-11-04 簡素化版。詳細は `セキュリティ設計.md`）

- 起動時にパスワードを 1 つ求める（全員共有）。役割分け・自動ロックは無し。
- 起動パスワードをそのまま DB（SQLite + SQLCipher）の暗号鍵にする。
- 終了時に DB ファイル 1 つを指定フォルダへ上書きコピー（指定が無ければ何もしない）。
- 「いつ・何を」の簡単な記録（確定・印刷・取込）。
- 外へ出る通信は持たない。タブレット入力用に、専用 Wi-Fi 側のアドレスにだけ入力ページを配る（PIN 付き）。PDF は文字抽出のみ。帳票の全ページに ID と氏名。
- PC は BitLocker 有効。プリンタのあるネットワークに**ゲートウェイ無しの固定 IP**で接続し、インターネットへの経路を持たない（Windows の設定。コード無し）。ネットワーク探索・ファイル共有は切る。
- **既定ゲートウェイを持つアダプタがあれば起動しない。起動後に現れればロックする**（通信はしない）。ネットワークプリンタへの印刷はこの条件で可能。

## 個人情報

- すべて閉域の PC 内。リポジトリにもテストデータにも実在の患者情報は入れない（架空の値を使う）。
- 開発中の帳票の見た目の確認は架空の受診者で行う。

## 一般的な健診システムとの比較で足したもの（2026-11-04、詳細は `一般的な健診システムとの比較.md`）

- **コース**（企業健診・人間ドック・雇入時など）とオプションを設定ファイルで定義し、受診者ごとに付ける。コースで入力項目・必須項目・帳票の欄が決まる。
- **受診者の複数 ID**（ファルコの個人 ID、院の診察券番号、事業所の社員番号）。取り込みの突合に使い、履歴をつなぐ。
- **必須項目の漏れチェック**（コースの必須項目が未入力なら確定時に警告）。
- **実施医師名・産業医名**の設定（受診者ごとに上書き可）。
- **確定時に帳票の PDF を保存**し、再発行・訂正の版を残す。
- **未完了一覧**（入力中→所見待ち→血液待ち→確定→郵送済）と**宛名印刷・郵送日の記録**。
- 第 4 段階として**要精密検査・要再検査の追跡一覧**。
- 特定健診の XML、事業所向け帳票、協会けんぽ・自治体検診の様式は、先生の確認結果で要否を決める。
