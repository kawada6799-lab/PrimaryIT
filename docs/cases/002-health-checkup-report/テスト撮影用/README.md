# テスト撮影用（架空の 3 人）

携帯で撮って読み取りを試すための紙です。**すべて架空の値**（実在の患者ではない）。印刷して、手持ちの携帯で撮って、確認画面の赤（要確認）の数と読み違いを見てください。

| ファイル | 内容 |
|---|---|
| `入力シート_テスト3人.pdf` | 白紙の入力シートに **手書き風** で記入済み（3 枚）。先頭の受診者のマス（個人ID・実施日・生年月日・性別）も記入済み |
| `入力シート_白紙.pdf` | 記入していない白紙（本番と同じもの。自分の手で書いて試す用） |
| `採血報告書_テスト3人.pdf` | ファルコの検査報告書を模した 6 枚（1 人 2 枚：1/2・2/2）。左右に同じ値が 2 回印字された並び、↑↓ の印 |
| `期待値_入力シート.md`／`期待値_採血報告書.md` | 読み取った値が正しいかを突き合わせる答え |
| `*.png` | 同じものの画像（携帯に送って画面から取り込む用、A4 150dpi／1512×2016） |

## 試す順

1. `入力シート_テスト3人.pdf` と `採血報告書_テスト3人.pdf` を印刷（A4、等倍）。
2. プログラムで受診者を **登録せずに**、最初の画面の「📷 入力シートを撮る」で 1 枚撮る → 受診者のマスから「一致する受診者がいない」→ 氏名を入れて登録 → 確認画面で赤を直して保存。3 人分。
3. 受診者を開いて「血液検査」タブの「📷 報告書を撮る」で 1/2・2/2 を撮る → 確認 → 保存。
4. `期待値_*.md` と見比べる。読み違いがあれば、その写真（架空なので送ってよい）を開発者へ。

作り方（開発者）：入力シートは `dotnet test` の `TestSetDevTests`（環境変数 `KENSHIN_TESTSET_DIR`）、報告書は開発者の手元の `make_testset.py`。
